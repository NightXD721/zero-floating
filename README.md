# Zero Floating

## 1. Fungsi aplikasi

Zero Floating adalah asisten AI bernama Zero yang melayang di atas layar HP. Gunakan untuk bertanya, menanyakan isi layar atau foto, menerjemahkan teks pada gambar seperti halaman manhwa dan novel, serta mengirim file ke AI. Zero memakai API key milikmu sendiri dari Google AI Studio (Gemini) atau Groq, tanpa server perantara.

## 2. Fitur-fitur

- Dua penyedia AI: Google AI Studio (Gemini) dan Groq, dengan pilihan model atau ID model sendiri.
- Tutorial bikin API key gratis di dalam aplikasi.
- Tiga mode:
  - Overlay: bubble melayang di atas aplikasi lain.
  - Baca manhwa dan novel: web dibuka di dalam aplikasi, teks dan gambar halaman langsung ditimpa dengan terjemahan.
  - Biasa: obrolan layar penuh dengan Zero, tanpa membuka web.
- Bubble melayang yang bisa digeser, dengan pengaturan transparansi, ukuran, tempel ke tepi, dan redup saat diam.
- Tanya lewat foto kamera, atau lewat crop layar dan layar penuh di mode Overlay.
- Terjemah langsung di tempat pada mode Baca: teks web dan teks di dalam gambar manhwa diganti ke bahasa pilihanmu, bisa dikembalikan ke asli kapan saja.
- Auto terjemah saat berhenti scroll di mode Baca.
- Terjemah crop atau layar penuh di mode Overlay, dengan bahasa tujuan yang bisa dipilih.
- Terjemah gambar paling akurat memakai Gemini. Groq tetap bisa, tapi kurang stabil.
- Lampiran chat: galeri, kamera, dan file (gambar, PDF, teks, kode).
- Cara kerja Cepat, Sedang, Tinggi, dan mode berpikir yang prosesnya bisa dilihat.
- Panel chat dan kartu terjemahan yang bisa digeser dan diubah ukurannya di mode Overlay dan Baca.
- Tampilan rapi untuk matematika, kimia, fisika, tabel, kutipan, dan blok kode.
- Pindah otomatis ke model cadangan saat server sedang sibuk.
- Jalan di perangkat 32-bit dan 64-bit.
- API key hanya tersimpan di perangkatmu.

## 3. Cara instalasi

Kebutuhan: Android 8.0 atau lebih baru dan koneksi internet.

1. Buka github.com/NightXD721/zero-floating/releases.
2. Unduh file APK pada rilis terbaru.
3. Buka file APK tersebut.
4. Jika diminta, izinkan pemasangan dari sumber ini.
5. Tekan Instal.

Untuk memperbarui, pasang APK rilis terbaru di atas aplikasi yang lama. Pengaturanmu tetap aman.

## 4. Cara menjalankan

1. Buka Zero Floating.
2. Pilih Google AI Studio atau Groq, tempel API key, pilih model, lalu tekan "Tes dan lanjut". Belum punya key? Tekan "Tutorial bikin API key gratis".
3. Tekan "Buka pengaturan izin", aktifkan izin tampil di atas aplikasi lain, lalu kembali. Izinkan notifikasi jika diminta.
4. Isi alamat web jika ingin memakai mode Baca, atau tekan "Lewati, isi nanti".
5. Pilih mode dan bahasa terjemahan, lalu tekan "Simpan dan mulai".
6. Mode Overlay: setujui izin tangkap layar, lalu tekan bubble Zero di aplikasi mana pun untuk membuka menu.
7. Mode Baca: tekan "Mulai Zero" di layar utama, tekan bubble di dalam halaman, lalu pilih "Terjemah halaman". Nyalakan "Auto terjemah" agar halaman diterjemahkan setiap berhenti scroll, dan pilih "Tampilkan asli" untuk mengembalikan teks.
8. Mode Biasa: tekan "Mulai Zero" di layar utama, lalu ketik pertanyaan atau tekan + untuk melampirkan gambar, foto, atau file.
9. Untuk mematikan bubble di mode Overlay, pilih "Matikan bubble" di menu bubble atau "Matikan" di notifikasi.
